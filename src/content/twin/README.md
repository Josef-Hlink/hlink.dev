# twin

a little go cli that builds tmux sessions from toml recipes.

born from my obsessive need to automate boring stuff. opening the same
windows — editor, lazygit, a log tail — every single day. twin folds
all of that into a recipe you write once and forget.

    twin tspmo     spin up the main sessions
    twin fr        open one from a fuzzy popup
    twin sybau     hop between running sessions
