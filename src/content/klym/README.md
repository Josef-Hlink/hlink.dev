# klym

turn a gpx ride into climbfinder-style climb profiles.

upload a track, browse it on a map with a synced elevation chart,
and klym finds the climbs for you — length, gain, grade, category.
crop your own segments with a/b markers and export the colored-bar
profile as png or svg.

built with sveltekit + maplibre + uplot, self-hosted on my homelab
like everything else around here.
